# Funnel 01 — Course Naming + Cover Decision V1

Status: CURRENT FOUNDER DECISION
Date: 2026-09-23

Purpose: record the approved customer-facing name of the Formalife Full live flagship and the required opening cover slide for the production deck.

## 1. Customer-facing course name

**Corso Anti-Panico sulle Emergenze Pediatriche**

This is the current founder-approved name for the broader Formalife Full live course.

It replaces the prior open naming state in `FUNNEL_01_G3_FULL_OFFER_ARCHITECTURE.md` where the final customer-facing Full name was still listed as open.

## 2. Required cover slide

The PowerPoint must begin with one dedicated presentation/cover slide before `S01`.

Working ID:

**C00 — COVER**

The cover is outside the official 00:00–04:10 teaching clock and may remain projected while participants enter the room.

Required primary text:

**Corso Anti-Panico sulle Emergenze Pediatriche**

Recommended supporting elements:

- Formalife logo;
- restrained ordinary-life/family visual or Formalife brand field;
- optional edition date/location;
- optional `Iniziamo alle __:__` while used as the pre-start holding state.

Do not add:

- Course Rail;
- learning content;
- statistics;
- emergency imagery;
- agenda;
- offer/referral content;
- dense instructor biographies.

At official start time, `C00` cuts/fades to `S01 — RICONOSCERE. DECIDERE. AGIRE.`

## 3. Deck-count consequence

Current production baseline becomes:

- **1 mandatory cover slide (`C00`) outside the official clock**;
- **69 active teaching slides** across the official course, using the current Cue Sheet numbering (`S01`–`S68`, with `S19A` + `S19B`);
- **7 hidden ACT 6 scenario-bank slides**;
- appendix/reference slides excluded.

Therefore the normal visible production deck contains **70 physical slides before hidden scenarios/appendix**.

## 4. Supersession note

Where `FUNNEL_01_FULL_SLIDE_BLUEPRINT_V2.md` or `FUNNEL_01_SLIDE_CUE_SHEET_V1.md` still describe `P00` as an optional pre-start slide, this decision supersedes that status: the course cover is now **mandatory**, not optional.

The old `P00` pre-start job is absorbed into `C00` rather than adding a second redundant holding slide.

## 5. Revision condition

Revisit the course name only through a new explicit founder decision. Deck design may refine typography, imagery and edition metadata without changing the approved name.
