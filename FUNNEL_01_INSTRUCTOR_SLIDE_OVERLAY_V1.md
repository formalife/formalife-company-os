# 2. Morph doctrine — approved production direction

Founder preference: use Morph more than V2 originally planned.

Decision:

**use Morph whenever the audience should perceive that the new slide is the same mental object changing state.**

Do not use it merely to make the deck feel premium.

Morph should be relatively quick and restrained. The semantic change must be noticed before the transition effect itself.

## 2.1 High-value Morph uses

### FVA family

- S12 -> S13
- S13 -> S14
- S14 -> S15
- S15 -> S16

Keep `FERMA | VALUTA | AGISCI` in stable spatial positions. The current phase expands while the other two recede; retrieval returns them to equal weight.

### Choking anatomy / state family

- S19A -> S19B
- S19B -> S20
- S20 -> S21
- S21 -> S22 where practical
- S22 -> S23 only after the child demo/deconstruction is finished

The same airway/decision structure visually evolves from vulnerability -> airflow -> obstruction state -> observable cough -> child action.

Child-to-infant transition preserves the same decision skeleton while age-specific technique changes.

### Choking outcome / 112 family

- S28 -> S29

The unresolved branch remains visible and transforms into role assignment / emergency activation rather than looking like a new unrelated topic.

### Pediatric CPR family

- S34 -> S35
- S35 -> S36
- S37 -> S38

Ventilation/AED concepts from the pediatric translation become the algorithm. The algorithm then remains spatially stable while rescuer roles appear around it. Child and infant demo slides preserve the same algorithm skeleton while technique landmarks change.

### ACT 5 paired-topic slides

Use Morph inside each two-slide topic pair:

- S45 -> S46 — ingestion: identify/risk -> act/escalate;
- S47 -> S48 — head trauma: recognise -> decide/escalate;
- S52 -> S53 — anaphylaxis: recognise -> adrenaline/112;
- S54 -> S55 — drowning: water safety/recognition -> post-removal response.

The persistent six-step grammar remains fixed while active content moves from earlier to later steps.

### ACT 6 debrief

- S61 -> S62

The restaurant/context image can shrink into the `ADESSO` side of the debrief comparison. The baseline meal context can reappear as the `INIZIO` side. The Morph makes the before/after relationship visible without a numeric score.

## 2.2 Optional subtle Morph

Within ACT 5, the common six-step header may be named consistently so that even when the full transition is a Fade/Cut, PowerPoint can preserve a small amount of spatial continuity. Do not force full-slide Morph between unrelated emergencies if photography or anatomy would visibly warp.

## 2.3 Explicit no-Morph transitions

Do **not** Morph:

- S33 adult survival evidence -> S34 pediatric translation: a hard visual distinction protects against transferring adult quantitative evidence to children;
- pre-break question -> break screen;
- break screen -> ACT 4;
- live QCPR feed -> retrieval if Morph would visually imply the QCPR score is the algorithm;
- S67 admin/QR -> S68 final bookend: use a clean Fade or Cut so the commercial/operational layer is psychologically removed;
- between unrelated ACT 6 scenarios unless the effect remains effectively invisible.

# 13. Production rule going forward

When the actual PowerPoint is built, slide notes should be authored from this overlay in a strict three-line format:

**SAY / SHOW / CLICK**

Example:

- `SAY:` “La tosse è ancora efficace...”
- `SHOW:` effective-cough branch only;
- `CLICK:` reveal ineffective-cough branch when the instructor says the state has changed.

This will preserve synchronization during rehearsal and make the deck transferable between instructors without turning notes into a full teleprompter script.

Current baseline after synchronization:

**69 active slides + 7 hidden scenario-bank slides + 1 optional pre-start slide.**

The deck flow is now logically continuous with the instructor flow; remaining uncertainty is clinical wording/sign-off and rehearsal evidence, not slide-order architecture.
