# 2. Global audit rules added to the deck doctrine

## 2.1 One dominant visual claim

When a slide contains multiple valid facts, only one may behave as the protagonist unless comparison itself is the learning job.

Secondary evidence belongs in:

- subordinate visual treatment;
- instructor speech;
- notes;
- appendix/reference.

Do not preserve a statistic on screen merely because it is valid.

## 2.2 Measured object boundary

When the deck shows a measurement tool or live feed, explicitly protect against the learner confusing the measured component with the complete skill/system.

This applies especially to QCPR.

## 2.3 No double navigation

When a section has a stronger local cognitive grammar, suppress the global Course Rail if both would compete for persistent attention.

ACT 5 uses this rule.
